# **App Name**: SmartVest

## Core Features:

- Package Display: Display available investment packages with details like purchase price, weekly profit percentages, and referral bonuses.
- Purchase: Enable users to purchase investment packages using wallet balance.
- Referral System: Track user referrals and calculate referral income based on referred user purchases. A tool could be used to decide what share is given as referral income based on the status of users and system conditions.
- Wallet Management: Provide users with a wallet to store funds, track transactions (purchases, referrals, withdrawals, profits), and manage their balance.
- Profit Calculation: Calculate and credit weekly profits to user wallets based on their active packages.
- Withdrawal Requests: Allow users to submit withdrawal requests for available funds in their wallet. AI-driven anomaly detection can be implemented to verify the validity of each withdrawal.
- Transaction History: Show list of transactions history, filtering by time

## Style Guidelines:

- Primary color: Deep sky blue (#4169E1), reflecting reliability.
- Background color: Light gray (#F0F8FF), a soft and neutral backdrop.
- Accent color: Yellow green (#9ACD32) to highlight important information, like profit.
- Font: 'Inter', a sans-serif font known for its legibility and modern appearance. To be used for headers and body.
- Use a set of simple and consistent icons related to investments, wallets, and transactions.
- Clean and intuitive layout that facilitates easy navigation and understanding of financial information.
- Use subtle transitions and animations to enhance user experience.
